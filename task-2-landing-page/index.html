Declarative Infrastructure as Code

Branch-Based Environments

Every Git branch automatically gets its own isolated staging URL.

novacloud.yaml — configuration YAML 
# NovaCloud Cluster Orchestration Specification
version: "3.0"
service: "web-frontend-api"

runtime:
  framework: "react-spa"
  node_version: "22.x"
  build_command: "npm run build"
  output_dir: "dist"

deploy:
  strategy: "rolling-canary"
  regions:
    - "iad1" # US-East (Virginia)
    - "fra1" # EU-Central (Frankfurt)
    - "sin1" # AP-South (Singapore)

security:
  auto_tls: true
  ddos_protection: "strict"
  csp_headers: "enforced"
